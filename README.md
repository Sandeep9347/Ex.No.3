```
Procedure and Examples:

1. Straightforward Prompts:

Prompt: "Define photosynthesis in one sentence."
Response: "Photosynthesis is the process by which plants convert sunlight, water, and carbon dioxide into glucose and oxygen."

Prompt: "List three advantages of electric vehicles."
Response: "1. Reduce greenhouse gas emissions. 2. Lower running costs. 3. Quieter operation and reduced noise pollution."

2. Tabular Format Prompting:

Prompt: "Compare and contrast AC and DC current in a table."
Response:

Feature	AC (Alternating Current)	DC (Direct Current)
Flow	Alternates direction	Flows in one direction
Source	Generators, Power grids	Batteries, Solar cells
Usage	Household appliances	Electronics, Batteries
Transmission	Efficient over long distances	Inefficient over long distances

Prompt: "Provide a table listing five programming languages, their paradigms, and one use case each."
Response:

Language	Paradigm	Use Case
Python	Object-Oriented, Procedural	Data Analysis
Java	Object-Oriented	Web Applications
C	Procedural	System Programming
JavaScript	Event-driven, Functional	Web Development
R	Functional	Statistical Computing

3. Preceding Question Prompting:

Prompt: "Why is climate change a global concern? Explain how greenhouse gases contribute to global warming."
Response: "Climate change affects weather patterns, sea levels, and biodiversity globally. Greenhouse gases trap heat in the Earth's atmosphere, leading to global warming and its associated impacts."

Prompt: "How do vaccines work? Describe the process of immunization in simple terms."
Response: "Vaccines introduce a harmless part of a pathogen to stimulate the immune system. The body learns to recognize the pathogen and can fight it effectively if exposed later."

4. Missing Word Prompting:

Prompt: "The capital of France is ____."
Response: "Paris"

Prompt: "In photosynthesis, plants absorb sunlight to produce ____."
Response: "Glucose"
```
